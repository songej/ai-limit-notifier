Privacy Policy

Last updated: October 4, 2026

In short

AI Limit Notifier works locally in Chrome. It shows ChatGPT and Claude usage limits, reset times, and optional alerts, and can continue a recent conversation only after you click Continue conversation.

The extension has no developer-operated backend, analytics, advertising, or separate account system. Provider requests go directly from your browser to ChatGPT or Claude using the session already signed in there. The developer does not receive or sell extension data. Conversation history is not read.

Data handled locally

  • Usage data: normalized usage percentages, reset times, provider state, and the last successful result can be stored in chrome.storage.local so the popup and badge can render quickly and temporary failures can show a labeled last-known value.
  • ChatGPT account scope: a short-lived access token returned by ChatGPT can be used in memory for the usage request and is never stored. When available, an internal account/workspace ID is reduced to a one-way SHA-256 fingerprint so state from one account does not carry into another. The raw account/workspace ID is not stored.
  • Claude organization scope: eligible organization names can be shown temporarily while you choose one. The selected organization ID and one-way SHA-256 fingerprints used to keep scopes separate can be stored locally. Organization names and account email addresses are not stored.
  • Continue target: for each enabled service, chrome.storage.session can temporarily hold one recent target: normalized conversation URL, conversation ID, tab and window IDs, last-seen time, and whether it is currently in view. A shortened title is added only when a reached-limit episode captures that target. Conversation history is not read.

The shortened title can appear in the extension popup so you can verify the target. It is not displayed in the operating-system reset notification, which may appear on a lock screen or during screen sharing.

Continue conversation

Only after you click Continue conversation does the extension run a one-time script in the named ChatGPT or Claude conversation tab. It verifies the exact conversation, checks the composer locally, preserves any existing draft, inserts the chosen continue word only when the composer is empty, submits it, and confirms that the composer cleared.

Composer text is never stored by the extension or sent to the developer or another server. The continue message goes directly to the selected provider conversation as the action you requested.

Notifications and device activity

The extension can notify you after a fresh check confirms that a reached limit has reset. Optional settings can also enable one 90% warning per limit window, model-limit reset alerts, Continue outcome notices, and test notifications.

Chrome's idle API is used only to pause periodic checks while the computer is idle or locked and resume them when it becomes active. Active, idle, or locked state is not stored or transmitted.

Permissions and network access

  • storage: stores settings, usage/reset state, opaque scope fingerprints, the Claude organization ID in use, and short-lived Continue metadata.
  • alarms: schedules periodic checks, reset checks, retries, badge countdown updates, and Continue cleanup.
  • notifications: shows the optional notifications described above.
  • scripting: runs the one-time Continue script only after your explicit click.
  • idle: pauses unnecessary checks while the device is idle or locked.
  • https://chatgpt.com/* and https://claude.ai/*: optional host permissions requested only for services you enable. They are used for usage checks and the user-triggered Continue flow, and are removed when that service is disabled.

The extension does not request Chrome's cookies permission, does not use remote executable code, and does not send extension data to an analytics, advertising, or developer-operated service.

Chrome Web Store Limited Use

AI Limit Notifier adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide or improve the extension's disclosed single purpose. It is not used for advertising, creditworthiness, profiling, or unrelated purposes.

Retention and deletion

Persistent settings and usage state remain in Chrome extension storage until replaced, cleared by Chrome or the user, or removed with the extension. Continue-target metadata is session-only and is also cleared when it is no longer eligible, used, expired, or the service is disabled. Turning a service off removes that service's stored usage and limit state and its optional site permission.

Third-party services and contact

ChatGPT is provided by OpenAI and Claude by Anthropic; their own privacy policies govern data processed by those services. AI Limit Notifier is independent and is not affiliated with or endorsed by either provider.

This policy is updated when the extension's data handling changes. Questions go through the contact form.
